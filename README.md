# Lux Lustra

Интернет-магазин люстр на HTML, CSS и JavaScript. Проект демонстрирует каталог товаров, фильтрацию, корзину и оформление заказа.

## Возможности

- главная страница с промо-блоком и популярными товарами;
- каталог люстр;
- фильтры по типу, стилю, цвету, материалу и подбору;
- сортировка товаров;
- карточка товара с описанием и характеристиками;
- корзина;
- форма оформления заказа;
- административная часть для управления товарами и заказами.

## Стек

- HTML
- CSS
- JavaScript
- localStorage для демо-данных

## Структура

```text
html/         страницы сайта
css/          стили
JS/           клиентская логика
robots.txt    настройки индексации
sitemap.xml   карта сайта
```

## Запуск

Откройте файл `html/index.html` в браузере.
