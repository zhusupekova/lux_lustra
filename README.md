# lux_lustra— интернет-магазин люстр 🛒 


🚀 О проекте

lux_lustra — это веб-приложение, позволяющее пользователям просматривать каталог люстр, фильтровать товары, изучать характеристики, добавлять позиции в корзину и оформлять заказ.

Проект включает также административную панель для управления товарами и заказами.


🎯 Цель разработки

Создать современный, быстрый и удобный интернет-магазин премиального стиля, который позволит пользователям легко выбирать и заказывать люстры, а администратору — управлять товарами и заказами через удобную административную часть.


✨ Основные возможности

🔹 Пользовательская часть
	•	Главная страница с промо-баннером и популярными товарами
	•	Полноценный каталог
	•	Фильтры по:
	•	типу
	•	стилю
	•	цвету
	•	материалу
	•	цене
	•	Сортировка товаров
	•	Просмотр карточки товара (фото, цена, описание, характеристики)
	•	Добавление товара в корзину
	•	Управление корзиной
	•	Оформление заказа (имя, телефон, адрес, комментарий)

🔹 Административная панель
	•	Авторизация администратора
	•	CRUD-операции над товарами
	•	Управление заказами
	•	Изменение статусов заказов


🎨 Дизайн

Проект выполнен в премиальном стиле:
	•	Белая светлая основа
	•	Акцентные цвета: чёрный и золотой
	•	Чистая типографика
	•	Плавные hover-эффекты
	•	Удобная навигация (header + footer)

🧱 Структура сайта
	1.	Главная
	2.	Каталог
	3.	Фильтры/поиск
	4.	Карточка товара
	5.	Корзина
	6.	Оформление заказа
	7.	Контакты
	8.	Админ-панель
